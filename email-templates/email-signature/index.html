Install it in 60 seconds

Use Copy signature for Gmail and Outlook. Use Copy HTML code only if a client asks for code.

Gmail

  1. Click Copy signature above.
  2. Gmail → gear icon → See all settings.
  3. Under Signature, click Create new, name it "Cruz Creative".
  4. Paste into the box. Set it as the default for new emails and replies.
  5. Scroll down and hit Save changes.

Outlook

  1. Click Copy signature above.
  2. Web / new Outlook: Settings → Account → Signatures. Classic desktop: File → Options → Mail → Signatures.
  3. Add a new signature and paste.
  4. Pick it as the default for new messages and replies. Save.

Apple Mail

  1. Click Copy signature above.
  2. Mail → Settings → Signatures, pick your account, click +.
  3. Untick Always match my default message font.
  4. Paste into the preview pane. Close settings to save.
